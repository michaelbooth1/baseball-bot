PART 2: TEAM-OFFENSE V2 CALIBRATION (Phases 1-5)
=================================================

Phase 1 -- Build leakage-free residual training table
------------------------------------------------------
Builder:    scripts/analysis/build_team_offense_calibration_table.py
Reports:    scripts/analysis/report_team_offense_residuals.py
            scripts/analysis/report_team_offense_mle_deltas.py
Output:     data/analysis_output/team_offense_calibration/
              training_table.jsonl              (1,129,081 rows)
              manifest.json
              phase1_residual_report.json
              phase1_mle_deltas.json

For each (game_pk, half-inning boundary, line) in 2021-2026 with
Stage-1 cell coverage, computed Stage-1 + Stage-2 FV (Stage-3 OFF) and
joined the realized over_hit outcome. The residual `over_hit -
base_fv_stage1_plus_stage2` is the Stage-3 calibration target.

HEADLINE: Empirical per-run logit slope is +0.062 (MLE). Current
production v1 used 0.20. **Current Stage-3 is ~3.2x too aggressive.**

Other findings:
  - Stage-1+2 alone has near-zero overall residual (-0.0001) but the
    bias the current Stage-3 targets is real and monotonic in offense-
    diff (-0.167 logit at <=-1.5 runs vs MLB total, +0.102 at >=+1.5).
  - Asymmetric: low-offense matchups need larger absolute correction
    than high-offense.
  - Per-inning MLE deltas are roughly FLAT from innings 1-6, then drop
    sharply at 7-9 -- NOT a linear ramp. v1's `(9-inn)/8` weight dials
    the prior down too aggressively in mid-innings.

Phase 2 -- Feature library
---------------------------
Builder:    scripts/analysis/build_team_offense_features.py
Report:     scripts/analysis/report_team_offense_features.py
Output:     team_features.jsonl (23,980 rows, leakage-free per-(team,date))
            phase2_feature_report.json

Computed all candidate offense windows per (team, date), strictly
before-date: prior_season_rpg, season_rpg_to_date, momentum_5/10/20,
rolling_50, decay_weighted (half-life 15), home_rpg_30, road_rpg_30,
plus derived `momentum_minus_season` and `season_minus_prior`.

Sanity finding: short-window momentum (5-10 games) is essentially
anti-predictive of next-game runs (momentum_5 MSE is 20% WORSE than
predicting the league mean). Long windows (50, decay-weighted, season)
carry the actual signal. Single-feature Pearson r at next-game level
is < 0.10 across all features -- single-game runs are very noisy, but
the SUM across both teams + game-state conditioning is what matters
for over_hit prediction.

Phase 3+4 -- EB shrinkage + walk Models 1-5 up complexity ladder
-----------------------------------------------------------------
Script:     scripts/analysis/calibrate_team_offense_v2.py
Output:     phase4_models.json

Time-respecting split:
  Train      2021-2024  (654,173 rows)
  Validation 2025       (202,729 rows)
  Test       2026       (2,932 rows -- partial season, dollar-test only)

EB shrinkage parameters estimated from training years:
  sigma_within^2 = 10.001 (single-game runs variance around team RPG)
  tau_sq:  rolling_50=0.179, season=0.237, prior_season=0.171, mom10=0.198
  shrinkage_k (equivalent prior games):  rolling_50=55.7, season=42.1,
                                         prior_season=58.4, mom10=50.5

Models scored on validation Brier (with logit(base_fv_stage1_plus_stage2)
entered as offset, so we measure incremental Stage-3 contribution):

  Baseline A    no Stage-3
  Baseline B    current v1 (LOGIT_DELTA_PER_RUN=0.20, hard clamp,
                            linear ramp) -- reproduced for comparison
  Model 1       same shape as B, refit constant on training data
                  -> beta_diff = +0.1125  (0.56x v1's 0.20)
  Model 2       Model 1 with EB-shrunk rolling_50 instead of clamped raw
                  -> beta_diff = +0.2376 (higher because shrinkage already
                                           pulls extreme values toward mu)
  Model 3       Linear blend of (prior_season, season_to_date, momentum_10),
                EB-shrunk per window, refit
                  -> beta_prior   = -0.1514     <-- NEGATIVE
                     beta_season  = +0.1407
                     beta_momentum= +0.1503
  Model 4       Model 3 + per-inning multiplicative weights
                  -> Fit shape [1.0, 0.90, 0.78, 0.79, 0.58, 0.49, 0.31,
                                0.11, 0.24, 0.67]
                     overfits on validation; ties Model 3 on test.

  Model 5 (gradient-boosted residual): SKIPPED (deemed unnecessary).

Brier scores:
  model                       VAL_brier   TEST_brier   TEST vs B
  baseline_A_no_stage3        0.171341    0.151769     -0.07%
  baseline_B_v1               0.171409    0.151665     0.00%
  model_1_refit_const         0.171240    0.151621     +0.03%
  model_2_eb_shrunk           0.171240    0.151621     +0.03%
  model_3_blend               0.171204    0.150326     **+0.88%**
  model_4_blend_per_inn       0.171198    0.150388     +0.84%

Headline: Model 3 reduces Brier 0.88% on holdout test, 0.12% on val
(tiny absolute but ~20-sigma significant on 202k rows).

KEY structural finding: NEGATIVE coefficient on prior_season_rpg.
Once you condition on current-season pace and recent momentum, last
year's offense is a regression-to-mean correction term, not an
additive prior. A team that was elite last year but is now merely
average should LOSE Stage-3 lift, not gain it.

Phase 4.5 -- Sub-window stability check
----------------------------------------
Script:     scripts/analysis/phase45_stability_check.py
Output:     phase45_stability.json

Refit Model 3 on rolling sub-windows of the training data (2022 alone,
2023 alone, 2024 alone, 2021+2022, 2022+2023, 2023+2024,
2021+2022+2023, full 2021-2024).

Stability:
  b_prior negative in 8/8 sub-windows (range -0.10 to -0.23, mean -0.15)
  b_season positive in 8/8 (range +0.06 to +0.21)
  b_momentum positive in 7/8 (the one negative is the 2023-alone fit,
                              n=214k; small-sample artifact)
  Model 3 beats Baseline B on val Brier in 5/8 sub-windows (losses
                              cluster around 2024-as-validation)

The negative b_prior is structural, not noise. Greenlit Phase 5.

THE INTERACTION PROBLEM that emerged:

v1's edge distribution. v2 produces a different distribution (the
ATH@NYY case: v1 edge 0.223 was over the cap, v2 edge 0.166 is under).
Naive v1->v2 swap loses the protective effect of gate_extreme_edge on
those matchups.
