B. LATE-STAGE SKIP-WITH-FEATURES (the main work today)
------------------------------------------------------
Purpose: Family A-E features were only attaching to candidate rows on the
TRADE path. Yesterday produced 0 trades -> 0 feature captures. At ~5
fills/week we'd need 6+ months for the fill-model dataset. Now we also
capture features on the ~50-100 late-stage skip rows per session that
"look like real candidates" but ultimately get rejected by signal-quality
gates. This is a ~40x increase in fill-model training data accumulation.

Files touched:
  scripts/trading/signal_engine.py      — refactored 3 capture methods
  scripts/trading/signal_pipeline.py    — added LATE_STAGE_SKIP_GATES,
                                          _attach_skip_features, dispatch
                                          in _record_skip

Refactor (engine):
  _start_tape_capture(bet, ...)         -> _start_tape_capture(bet_id, ...)
  _start_family_b_capture(bet, ...)     -> _start_family_b_capture(bet_id, ...)
  _start_family_c_capture(bet, ...)     -> _start_family_c_capture(bet_id, ...)

  Sidecar paths now use bet_id directly:
    data/<paper|live>_trading/tape_captures/<date>/<bet_id>.json
    data/<paper|live>_trading/book_decision_snapshots/<date>/<bet_id>.json
    data/<paper|live>_trading/velocity_snapshots/<date>/<bet_id>.json
  For trade rows, bet_id is the existing bet_id (e.g. "2026-04-28_824609_8.5_0007").
  For skip rows, bet_id is "skip_<candidate_id>" (e.g. "skip_2026-04-28_824609_8.5_033902").

New dispatch in _record_skip closure:
  IF reason in LATE_STAGE_SKIP_GATES:
      dedup_key = (reason, game_pk, line, inning, inning_state, outs, current_total)
      if dedup_key not in self._skip_features_seen:
          - synthesize hypothetical_limit_price = bid + spread*spread_factor
          - call _start_tape_capture, _start_family_b_capture, _start_family_c_capture
          - compute Family D and E inline
          - mark payload['decision'] = 'skip_with_features'
          - add to dedup set
      else:
          - increment _skip_features_dedup_suppressed counter
